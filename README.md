# Подхват — тестовая версия мини-приложения

Кликабельный прототип, не боевое приложение. Все заведения и люди — пример.

Адрес: https://proto.podhvat39.ru

Исходник лежит в рабочей папке проекта: `design/2026-10-15_Прототип_Мини-приложение.html`. Обновление: собрать `index.html` из исходника и запушить в `main` — GitHub Pages выложит сам.

Версии — в `CHANGELOG.md`. Каждая итерация: +0.1, `VERSION` и строка в пульте в исходнике, метка `vX.Y` на коммит.
